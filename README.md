# Samarpan Hospital Website

This project is a frontend-only React website for Samarpan Hospital.
It includes the full landing experience, all pages, animated sections, blog content, and media assets without requiring any backend service.

## Run locally

From the frontend folder, run:

```bash
npm install --legacy-peer-deps
npm start
```

Then open http://127.0.0.1:3000 in your browser.

## Notes

- No backend server is required for the site to work.
- The app is designed as a static, self-contained frontend experience.
- The backend folder is kept only as an unused template and can be removed if you want to reduce project size further.
