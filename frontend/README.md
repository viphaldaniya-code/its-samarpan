# Samarpan Hospital Frontend

This is the standalone frontend for the Samarpan Hospital website.
It includes the full animated experience, all pages, blog content, and image assets without needing a backend service.

## Run locally

```bash
npm install --legacy-peer-deps
npm start
```

Then open http://127.0.0.1:3000 in your browser.

## Build for production

```bash
npm run build
```

The production build will be created in the build folder and can be served as a static site.
